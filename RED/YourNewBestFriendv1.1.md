# あなたの新しい親友

## サイバーペットとの暮らし方
サイバーペットの購入は安くない。そして維持費もまた、バカにならない。

まずは入手が第一。人気商品のため、フィクサーに頼るのが常套手段だ。
購入後は、ペットの「生活」を維持するために、食事、定期的なメンテナンス、
適切な居住空間を提供しなければならない。

ゲーム的にはライフスタイル（ルールブック P377）の費用を毎月支払う必要がある。
これはキャラ自身とは別に必要で、途中購入でも日割りはされず、1か月分フルで払う必要がある。

また、ペットにも寝る場所が必要で、住居（ルールブック P377）のベッドを消費する。

| レベル                        | ベッド         |
| ----------------------------- | -------------- |
| モブ（Mook）                  | 追加ベッド不要 |
| 中堅（Lieutenant）            | ベッド1つ分    |
| 中ボス（Mini-Boss）           | ベッド2つ分    |
| ボス級（harDeneD lieutenant） | ベッド3つ分    |

さらに……ペットOKなアパートでも「クマを飼っていい」とは限らないので、大家にも要確認だ。

## サイバーペットの訓練
サイバーペットに命令を聞かせるには技能が必要だ。
〈動物使い〉が10未満なら、ペットは命令を無視し、GMの裁量で行動する。

〈動物使い〉が10以上であれば、ペットはあなたを愛し、共に戦い、命令に従ってくれる。
ただし、これは日々のケアが適切であることが前提だ。

ライフスタイル維持を怠ったり、狭い空間でまともに寝かせなかったり、
虐待したり、信頼を裏切った場合は、GMがペットの行動を決めることになる。
逃げ出したり、命令を拒否したり、怒って襲ってくるかもしれない。
このような場合、GMが〈動物使い〉による判定を許可する可能性があるが、それは一時しのぎだ。
すぐに愛情・時間・手間・金を注がなければ、また暴走する。

## サイバーペットの拡張
ペットにサイバーウェアを追加する場合、判定の難易度は人間と同じだ。
だが当然、どこの病院でもネズミにサイバーアームを付けてくれるわけじゃない。
必要なのは〈科学（生物）〉レベル4以上のメドテクと、専用の施設だ（GMの裁量）。
これがないと手術は失敗し、ペットは命を落とす。

多くの人間用サイバーウェアは、動物用にも対応したバージョンが存在する。
ただし動物用のサイバーウェアは種族固有のモノだ。
種族間の互換性を持たせるためにはテクの〈改造エンジニア〉が必要だ。

そしてサイズも重要となる。
どんなに改造してもクマ用サイバーアイはネズミには入らないだろ？

ペットがインストールされたサイバーウェアを理解・使用できるためには、1日の訓練が必要となる。
そのためにはサイバーウェアのインストール難易度（ルールブック P226）
に対する〈動物使い〉に成功する必要がある。
失敗しても、ペットがお前に反逆することはない。
それは新しい身体に順応できず、判定に成功するまでは食べて寝ることしかできないからだ。

各サイバーペットは初期装備のサイバーウェアと追加スロットを持っている。
テクの〈改造エンジニア〉でスロット数を増やすことはできないが、
代わりに1つだけスロット数を0扱いにすることができる。
なお、ペットの初期装備をアンインストールしてもスロットは増えない。
新たにインストールしたサイバーウェアを外した場合のみ、スロットが空く。

## 新サイバーウェア一覧
このDLCで登場するサイバーペットには、以下のサイバーウェアが使用されています。
一部は『Black Chrome』、『Interface RED Vol.2』『Vol.3』、『Micro Chrome』からの収録品で、
Cyberpunk RED コアルールブックには含まれていないため、ここに再掲します。

※一部はテクの〈改造エンジニア〉 により強化されている場合があります。

### Chipware Compartment（チップウェア収納槽）
- 価格：100eb（Premium）  
- 装着場所：クリニック  
- 人間性喪失：1d6（平均3）  
- 種別：サイバーアイ・オプション（3スロット使用）

最大4つのチップウェアを隠し持つためのコンパートメント。  
アクションで眼球を回転させてチップを出し入れできる。

### Combat Jaw（戦闘顎）
- 価格：500eb（Expensive）  
- 装着場所：病院  
- 人間性喪失：4d6（平均14）  
- 種別：外部サイバーウェア（2スロット使用）

顎全体を油圧式の重機構造に換装。  
非常に重い近接武器（Very Heavy Melee Weapon）として機能する。

### FBC Chameleon Coating（FBCカメレオン・コーティング）

- 価格：1,000eb（Very Expensive）  
- 装着場所：病院  
- 人間性喪失：2d6（平均7）  
- 種別：外部サイバーウェア（FBC専用）

フルボディコンバージョン（FBC）に限定された光学迷彩機能。  
1分（20ラウンド）静止するとあらゆる視覚センサーから不可視になる。

- 赤外線／紫外線／暗視を含む
- 感知側は 難易度17 の知覚判定が必要
- 動いた瞬間（1ラウンドに2m超移動）で自動解除
- 2回目のインストールで静止時間が30秒に短縮
- 3回目で9秒まで短縮（これ以上は無意味）

###  Flashbulb（フラッシュバルブ）

- 価格：500eb（Expensive）  
- 装着場所：クリニック  
- 人間性喪失：2d6（平均7）  
- 種別：サイバーアーム・オプション（2スロット）

アクションで、視界内（25m以内）の対象に難易度15の耐光チェックを強制。  
失敗した対象は1分間「目の損傷」クリティカルを受ける。

※耐性を持つ者（例：Anti-Dazzle機能付き）は無効化可能。

###  Hardened Cybereye Casing（硬化型サイバーアイ筐体）

- 価格：500eb（Expensive）  
- 装着場所：クリニック  
- 人間性喪失：1d6（平均3）  
- 種別：サイバーアイ・オプション

EMP・マイクロ波・電撃、ブラックICE以外の電子攻撃に完全耐性。  
目と内蔵オプションが無効化・破壊されなくなる。

###  Homing Tracer Cyberfinger（ホーミング・トレーサー・サイバーフィンガー）

- 価格：500eb（Expensive）  
- 装着場所：モール  
- 人間性喪失：1d6（平均3）  
- 種別：サイバーフィンガー（Modular Fingerが必要）

1マイル（1.6km）以内にトレーサーがあれば、その方向を自動で指差す指。

- 交換用トレーサー爪：50eb（Costly）
