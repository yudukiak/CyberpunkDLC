# ナイトシティの天気 

## ナイトシティの天候について
2020年は、この大都市の気候を「温暖」と表現していました。
しかし数十年に及ぶ気候変動と、第4次企業戦争中に大気中へ放出されたガスや粒子の洪水により、現在では「不安定」という言葉の方が、ナイトシティの天気を語る上で適切でしょう。

平均気温は、冬季で摂氏約5℃、夏季で摂氏約32℃ですが、
極端な場合には氷点下近くや45℃超に達することも珍しくありません。
霧が出ることも多く、特に早朝や夕暮れ時には黄ばみがかった靄が街を覆います。
これは様々な汚染物質を含んでいるためです。
年間の降水量は約48センチと少なく、雷雨は年に2〜3回程度。
最後に雪が記録されたのは2022年、アラサカ・タワーが破壊された直後のことです。

ナイトシティは、海岸線の地形、長年続く干ばつ、2022年の核爆発、深刻な汚染、
そして世界規模の気候崩壊といった要素が組み合わさることで、異常気象の温床となっています。
酸性雨や逆転層スモッグに加え、砂嵐、血の雨、放射能を含む風などが発生する可能性もあります。
屋外で長時間過ごす予定のある者は、個人用防護装備の購入を検討すべきです。

## 天気の予測
場面設定において、天気は重要な要素です。映画を観たことがある人ならわかるでしょう。
登場人物が幸せなら太陽が輝き、悲しみに沈めば雨が降る。
ゲーム的に見れば、極端な気温や視界不良などによって、屋外での行動に実際の影響が及ぶ可能性があります。

ゲーム内の月に対応する「天気表」を使用し、次の2回ダイスを振って天気を決定します。
1回目は気温、もう1回は現在の天候です。

## 気温による影響
### 寒い 
通常の人間が耐えられる限界を下回る気温。
暖房のない屋外や室内に長時間滞在する場合、
適切な防寒装備がなければ「曝露」によるダメージを受けます。（CP:R p.181参照）

### 涼しい/暖かい
快適だが、日によって少し肌寒かったり蒸し暑く感じることがあります。機械的影響なし。

### 暑い
不快なほどの暑さ。
装備中の防具ペナルティに -1 を加算（例：防具ペナルティ -2 は -3 になる）。

## 天候による効果
### 大雨/みぞれ
大量の雨、または気温が低い時はみぞれとなり、地面が滑りやすく、視界も悪化します。
-2の技能ペナルティをGM裁量で適用可能（感覚・射撃など）

### 小雨/みぞれ
定番のサイバーパンク的風景。軽い雨やみぞれは視界には影響を与えませんが、足元は滑りやすくなります。
GM裁量で -1 のペナルティ
例：濡れたフェンスを登る（運動）／濡れた道路でのドライビング（車両操作）

### 放射性の強風
ホットゾーンの放射線はかつてよりは弱まったものの、風に乗って放射性粒子が他エリアに流れ込むことがあります。
放射線スーツなどの防護なしでは、高レベル放射線を受ける（CP:R p.181）
持続時間：1d6ラウンド（GM裁量で開始）

> 一部の公共施設（企業本社、高級ナイトクラブなど）には、出入口付近に除染シャワー／クリーニングブースが設置されており、
有毒気象から体を守ることができます。

### 灰の嵐
ナイトシティやバッドランドの火災によって、有毒な灰が風に乗って街へ流れ込むことがあります。
1分以上装備なしで晒されると、毒薬（CP:R p.355）の効果を受けると見なし、
「異物による致命傷」を負う可能性があります（初期ボーナスダメージはなし）。
治療は嵐を離れてからでなければできません。
また、GM裁量で感覚（Perception）や遠距離攻撃などの判定に -2 のペナルティを課すことができます。

### 洪水
2022年のアラサカタワー爆発でナイトシティの地盤は不安定化しました。
修復は進んでいますが、海水が亀裂から浸入して局地的な洪水を引き起こすことがあります。
地上 → 数センチの水位で大きな問題はなし
地下（地下鉄・トンネル・地下室など） → 深刻な水没
深い水域を移動する場合は「その他の移動手段」（CP:R p.169）ルールを適用。

### 血の雨
第4次企業戦争の残骸から生じた、ピンクがかった油性の降水。腐食性物質や毒素、放射性粒子を含みます。
1d6 を振って：
- 1〜3 → 酸性雨と同様の効果（ただし臭いが強烈）
- 4〜6 → 防護なしで1分ごとに生物毒（CP:R p.355）を浴びる判定  
さらに、GM裁量で判定に -1 のペナルティを適用可能。

### 酸性雨
ナイトシティの雨は基本的に弱い酸性ですが、稀に数時間で損傷を与えるほどの強酸が降ることがあります。
防護なしで1分間雨に晒されるごとに、着用中のアーマーのSPを1減少させます（アブレート）。

### 激しい雷雨
ナイトシティでは雷雨は稀ですが、発生時には極めて破壊的です。
10分ごとに1回、1d6を振ってください：
1～3 → 遠くで雷が落ちる
4～6 → その場の最も高い構造物または自然物に落雷
周囲に高い物がなければ：最も背が高いキャラクター、または両手で金属製の武器を持っているキャラクターに落ちる
キャラクター同士が触れていた場合（例：組み付き中）は両者が被雷
落雷を受けたキャラは：
6d6のダメージ
フラッシュバン（CP:R p.346）効果を受ける（中心点扱い）
さらに、GM裁量で -2 の判定ペナルティ（感覚・遠距離攻撃など）を適用可能。

### 逆転層スモッグ
CHOOH2への切替えにもかかわらず、ナイトシティでは濃霧のようなスモッグが依然として深刻です。
原因：産業毒素、火災、規制の緩さなど。
1分以上、防護装備なしで滞在すると毒薬（CP:R p.355）として扱う
GM裁量で、-4のペナルティを技能判定に適用可能（感覚・射撃など）

### 寒波（寒・涼）
気温が氷点下以下に急低下します。
通常の気温ロールを無視し、「曝露」のルールが強制されます（CP:R p.181）。
ブラックアイス（地面の氷結）が発生し、
滑る場所での判定には -2 のペナルティをGM裁量で適用可能。

### 熱波（暖・暑）
気候変動により、ナイトシティの気温が100～110°F（約38～43℃）に達する日が増加しています。
この場合、通常の気温ロールは無視されます。
曝露（CP:R p.181）ルールを適用
アーマーペナルティに +2 の追加修正（例：-2 → -4）


### 砂嵐
北カリフォルニアは2020年代から続く干ばつにより、
ナイトシティ周辺の土地は「バッドランド」と呼ばれる砂漠と化しています。
そこから巻き上がった粉塵が街へ吹き込むことがあります。
防護装備（鼻フィルター、対スモッグマスク等）なしで5分以上滞在すると：
「異物による致命傷」を負う（ただし初期ボーナスダメージはなし）
治療は嵐から離れないと不可
また、-2 の技能ペナルティをGM裁量で課すことができます。

### 停電（ブラックアウト） 
これは天候そのものではありませんが、
激しい気象により停電・通信障害・CitiNetの断絶が発生することがあります。
ランダムに決定するなら、1d10ブロックまたは地区で障害範囲を決定し、
その間は発電機がない建物では電力が使えず、エージェントはData Poolに接続不可となります。

## 新しい装備品
人類は昔から天候の悪影響に立ち向かうため、様々な装備を開発してきました。
そしてそれは、ダークフューチャーの時代になっても変わっていません。

Cyberpunk REDコアルールブックに記載された鼻フィルター、対スモッグマスク、放射線防護スーツに加えて、
以下のようなアイテムがナイトシティのエッジランナーに新たな選択肢をもたらします。

| -------------------------------- | ----------------- |

| 暑熱用ジャケットライナー         | 500eb（高価）     |
| ミリテク タクティカル アンブレラ | 1,000eb（超高価） |
| 傘                               | 10eb（安価）      |
| 防水ジャケットライナー           | 500eb（高価）     |

### 防寒用ジャケットライナー
既存のジャケット（CP:R 356ページ）の裏地として追加できる断熱素材のライナー。
極寒対策として有効。Exposureの対策装備として扱われる。

### 暑熱用ジャケットライナー
既存のジャケット（CP:R 356ページ）に適用可能。
汗を吸収し、小型ファンで熱を排出。
Exposureの対策装備として扱われ、暑さによるアーマーペナルティを1軽減。

### ミリテク タクティカル アンブレラ
ミリテック製エグゼク向け高級装備。酸性雨・血の雨を防ぎ、
かつ近接武器（優良品質）と重火器（劣悪品質）を兼ねる。弾倉は2発で、通常の重火器として扱う。

### 傘
ナイトシティ仕様の傘。酸性雨によるアーマー減少を無効化し、
血の雨に対して拷問／薬物耐性に+2ボーナス。
ただし、傘を持つ手では他の物を持てない。

### 防水ジャケットライナー
既存のジャケット（CP:R 356ページ）に塗布できる特殊な薬品。
酸性雨の影響を無効化し、血の雨に対して拷問／薬物耐性に+2ボーナスを付与。
ただし水中では効果なし。
